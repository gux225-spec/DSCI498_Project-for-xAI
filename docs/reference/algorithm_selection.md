# 微带滤波器全频响应代理模型：训练前技术选型

日期：2026-10-23。状态：完成资料核查与技术方案选择，尚未训练模型。本文件是实施备忘录和批判性方法建议，不是课程提交用的学术分析或报告正文。

## 选型结论

首选 **小型、平滑激活的频率条件 MLP**，学习 `[L1,L2,S1,S2,f] -> [S21_dB,S11_dB]`。解释阶段通过包装函数固定频率或频率集合，只向解释器暴露四个几何参数。把 Exact SHAP、Integrated Gradients、LIME 的比较和独立 ADS 反事实复核作为主要研究工作。

该方案是基于公开证据和当前任务条件作出的工程选择，不是已经在本数据上验证的性能结论。MLP 仍是需要解释的黑箱；层数少或可计算梯度不等于解释天然可信。

初期只保留三个实验项：原始频率 MLP、仅对频率做有限 Fourier 编码的 MLP 消融、PCA+GPR 小样本对照。后两者用于检验选择，不预设神经网络一定获胜。暂不同时铺开 Transformer、扩散模型、多个序列网络或复杂逆设计网络。

## 为什么当前选频率条件 MLP

当前正式数据为 480 个几何设计，其中训练集只有 336 个独立几何，不应把 201,936 个训练频点说成同样数量的独立设计。四个几何维度已经独立采样，空间较低维；频率条件 MLP 能直接回答指定频点的响应，也能通过固定 601 点网格重构完整曲线。

它允许原始几何变量贯穿前向预测、梯度、解释和反事实优化，方便统一比较三种解释方法。复杂可微模型同样可以使用 IG，因此这里选择 MLP 是为了控制实现与归因链路的复杂度，而不是声称其他网络无法解释。

当前 36 个多通带设计不适合作为“单一中心频率”的统一目标。训练使用完整曲线，解释主要面向固定频点和固定掩模的表现，避免依赖峰值分支选择或不可定义的整体带宽。

## 首轮模型与训练设置

主模型起点：5 输入 -> 三层 128 单元 SiLU -> 两个线性标量输出头。所有归一化只使用训练集统计量。AdamW、学习率 1e-3、weight decay 1e-4；最长 300 epoch、验证集早停 patience=30；三个固定种子检验重复性。这些是首轮工程设置，不是文献给出的最佳参数。

损失采用两个标准化 dB 通道的 Huber 损失，并对四类固定区域分别取平均后等权汇总：通带、低频阻带、高频阻带、两段过渡区域。区域边界沿用已有 mask，保持互斥完整覆盖，避免长阻带的点数淹没通带和边缘。

不删除深 S11 谷值，也不把低于某一阈值的原始标签改平。验证同时报告原始全曲线误差和工程相关区间误差；若 -80 dB 以下的窄谷仍不准，必须显示其误差及适用范围，不能用较好的平均误差代替。

Fourier 消融只编码归一化频率，使用有限的 sin/cos 频率组，几何输入不编码。只有在验证集上改善响应和边缘预测且没有明显振荡，才选择该变体。不默认更高频编码一定更好。

PCA+GPR 对照：仅由训练集的完整曲线拟合 PCA，使用四个几何参数预测系数，再重建曲线。精确 GP 在 336 个几何上拟合，不在 201,936 个频率行上拟合。PCA 截断阶数由验证集确定，并报告压缩重建误差，防止窄 S11 特征被压缩抹去。所有解释若用于该模型，也应解释整个解码后的几何到工程目标函数，而非把潜变量当作工程参数。

## 解释器的统一接口

先定义同一个几何标量函数 F(g)，再比较解释器：

1. 频点目标：固定 f* 后的 S21 或 S11，预设频点为 10.8、11.6、12.0、12.4、13.2 GHz。
2. 区域目标：固定通带/阻带的均值、最差值或明确记录温度的平滑近似。
3. 对比式工程目标：固定掩模违反量，解释“这个设计为什么比原始合格基线更差，以及改什么可能改善”。

所有解释必须在逆标准化后的工程单位上定义，或明确声明目标的无量纲尺度。频率作为外部固定查询条件；若目标是全带掩模函数，频率网格整体固定。不能让解释器通过改变频率来提出调谐方案。

### Exact SHAP

只解释 4 个几何特征，所以只有 2^4=16 个特征子集。采用完整子集枚举，减少 Kernel SHAP 的采样误差；每个子集仍要对选定背景平均，16 个子集不等于只做 16 次单点预测。

首先用原始 ADS 基线作为单参考，解释相对基线差异；随后用固定的 32 个真实训练设计检验背景敏感性。这里的“精确”仅相对于指定的有限背景、掩蔽规则和所定义的联盟博弈，不是对总体条件分布或真实因果贡献的精确识别。[官方 ExactExplainer 文档](https://shap.readthedocs.io/en/latest/generated/shap.ExactExplainer.html)

### Integrated Gradients

在同一个 F(g) 上，采用同一个物理参考基线，在原始几何与参考之间积分；标准化和目标聚合保留在可微计算图中。记录 completeness/convergence delta，必要时增加积分步数，并报告参考点变化对解释的影响。积分路径处于矩形参数域内不代表所有连续中间几何都已被 EM 或制造验证。[原论文](https://proceedings.mlr.press/v70/sundararajan17a.html)、[Captum 实现说明](https://captum.ai/docs/extension/integrated_gradients)

### LIME

对同一个 F(g) 拟合局部回归解释，使用域内几何扰动和明确的距离尺度；不把连续几何默认离散成无物理意义的类别。报告独立局部扰动点上的加权拟合质量，以及不同采样种子、核宽度的稳定性。若使用官方 LIME 默认采样器，必须检查其是否生成越界值；必要时使用显式有界邻域和加权局部回归，并披露这一适配。[原论文](https://arxiv.org/abs/1602.04938)、[回归 API 文档](https://lime-ml.readthedocs.io/en/latest/lime.html)

SHAP、IG、局部回归系数具有不同的参考和数学含义。不要要求它们数值相等，也不要把 SHAP 当作偏导数或直接的调节方向。

## 忠实性、物理一致性与工程效用分开评价

测试 A：解释是否描述了网络。检查数值加和/积分残差、局部代理预测误差、不同背景与种子下的稳定性；按方法含义选择特征干预或联盟响应测试。参数随机化只是额外诊断，不是忠实性的充分证明。[Yeh 等，NeurIPS 2019](https://arxiv.org/abs/1901.09392)

测试 B：网络的几何响应变化是否与 ADS 一致。对同一几何扰动比较完整曲线及同一个目标变化。预测误差小不保证梯度准确，忠实解释也可能忠实地描述一个错误代理。

最新的 [UAI 2026 工作](https://proceedings.mlr.press/v337/li26c.html)也表明，Shapley 的公理性质不自动保证某些干预排序指标上的可靠性。这不能推出 SHAP 无效，但支持我们不以漂亮排序图或三种方法一致作为最终证据。

测试 C：解释能否改进调谐决策。除全部四参数可调的代理优化和同预算坐标搜索外，加入“归因前 k 个参数”与“随机 k 个参数”的对照；其余优化器、约束和预算相同，以区分解释带来的收益和代理优化器本身的收益。归因排名决定候选参数集，具体方向和步长由目标重评估决定，不能直接由 SHAP 正负推导。

所有候选必须处于声明的四参数边界内，保持固定频率掩模，并独立回到 ADS 复算。记录 ADS 确认的成功率、几何修改幅度、残留违反量和仿真调用数。局部优化域内并不自动代表制造可行；本阶段仅主张该电路模型与已声明几何约束下的结果。

## 训练后进入解释阶段的门槛

先在验证集检查：全曲线和各固定区域误差、单通带/多通带分组表现、边缘位置误差、幅度非正与端口 1 功率一致性诊断、三种种子下的稳定性。不能从两条幅度曲线证明完整网络的无源性或因果性。

首轮数值目标在配套 JSON 中标记为暂定工程目标，不是公认行业标准或已达到的结果。若 S11 深谷或特定区域尚不可靠，不在这些位置给出工程有效性结论；应改善频率表达/代理结构，必要时再考虑复数响应或有理模型路线。

模型与超参数选择只使用 train/validation。已有的全数据完整性检查不用于比较模型优劣。72 个 test 几何保留到配置冻结后用于最终评价。现在不安装训练库、不拟合 PCA 或网络、不读取测试误差来筛模型。
